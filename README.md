# 📊 E-Commerce Sales Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze E-Commerce sales performance. It transforms raw sales data into meaningful business insights using data modeling, DAX calculations, and interactive visualizations.

The dashboard enables users to monitor sales trends, profit, customer behavior, product categories, and regional performance through an easy-to-use interface.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Track profit and revenue.
- Compare category-wise sales.
- Monitor monthly business performance.
- Analyze state-wise sales distribution.
- Identify top-performing products.
- Support business decision-making through interactive reports.

---

## 🛠️ Tools & Technologies
