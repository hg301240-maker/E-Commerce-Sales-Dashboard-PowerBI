# 📊 Madhav E-Commerce Sales Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** developed to analyze E-Commerce sales performance. It transforms sales data into meaningful business insights using interactive visualizations, KPIs, charts, and filters.

The dashboard enables users to analyze **sales, profit, quantity, product categories, sub-categories, payment modes, customers, and state-wise performance** through an easy-to-use interactive interface.

---

## 🎯 Objectives

* Analyze overall E-Commerce sales performance.
* Track sales amount and profit.
* Analyze quantity sold across product categories.
* Monitor monthly profit performance.
* Compare profit across sub-categories.
* Analyze state-wise sales distribution.
* Understand customer-wise sales performance.
* Analyze different payment modes.
* Identify top-performing product categories.
* Support business decision-making through interactive reports.
